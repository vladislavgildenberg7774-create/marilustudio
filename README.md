# MariluStudio

CRM для студий красоты: онлайн-журнал записей, клиенты, услуги, сотрудники и отчёты.

- Приложение: PWA (iOS, Android, ПК) — открывается по ссылке и ставится на экран «Домой».
- Хостинг: GitHub Pages (временно), затем свой сервер и домен.
- Данные и вход: Supabase.

## Роли
| Роль | Доступ |
|---|---|
| Суперадмин (владелец платформы) | Все студии, подписки, добавление и блокировка фирм |
| Владелец студии | Всё внутри своей студии |
| СММ-менеджер | Журнал и клиенты, без выручки, цен и управления сотрудниками |
| Мастер | Только свои записи и график |

## Запуск
1. Supabase → SQL Editor → по очереди выполнить `supabase/schema.sql`, `supabase/push.sql`, `supabase/002_superadmin_roles.sql`, `supabase/003_targeted_push.sql`, `supabase/004_moderation.sql`, `supabase/005_schedule.sql` (один раз).
2. Supabase → Authentication → URL Configuration → Site URL: адрес сайта на GitHub Pages.
3. Открыть сайт и зарегистрироваться. **Первый зарегистрированный пользователь становится суперадмином.**
4. В админ-панели создать студию и указать email главного — он регистрируется с этим email.

Файлы: `index.html`, `app.js` (логика), `styles.css`, `config.js` (адрес Supabase и publishable-ключ), `sw.js` (офлайн), `manifest.webmanifest` (установка как приложение).
